## Что нашли у них и как с этим у нас

| У них | У нас | Решение |
|---|---|---|
| Контекстное меню задачи (ПКМ и долгое нажатие): сделано дублирование, перенос, приоритет; быстрые даты уже были в окне даты: быстрые даты, приоритет флажками, подзадача, закрепить, не буду делать, «Переместить в», метки, «Сфокусируйся», «Дублировать», «Копировать ссылку», «В заметку», «Удалить» | Есть закрепить, не буду делать, подзадача, метки, дата, удалить, поделиться. Нет: дублировать, переместить в, приоритет и быстрые даты в меню, копировать ссылку | Делаем: дублировать, переместить в, приоритет и быстрые даты. Не делаем: «Сфокусируйся» (таймер отложен), «В заметку» (нет заметок), «Копировать ссылку» (ссылки на задачу вне приложения нет) |
| «Сортировать по» и «Группировать по» (произвольно, дата, дата создания, метка, приоритет) | Сортировка по сроку, важности, названию. Группировки нет | Делаем группировку по дате, метке, приоритету |
| Меню списка: вид (список, канбан, таймлайн), скрыть выполненные, показать детали, параметры просмотра, новый столбец, список активности, печать | Поиск, сортировка, вид список и канбан, настройки списка | Делаем: печать списка (отцу нужны бумажные листы бригаде). Таймлайн у них платный, не делаем. Список активности есть как история задачи |
| Меню списка в боковой панели: редактировать, закрепить, дублировать, поделиться, в архив, удалить | Редактировать, архив (закрыть), удалить. Нет: дублировать, закрепить | Делаем дублирование списка (шаблон объекта: этапы и типовые задачи копируются на новый объект) |
| Создание списка: имя, цвет, тип просмотра, папка, тип (задачи или заметки), показывать ли в умном списке | Имя, папка, цвет в карточке списка | Достаточно. Заметки как отдельный тип не делаем |
| Фильтры (платные): по спискам, дате, приоритету, метке | Нет. Метки и поиск есть | Делаем бесплатно: сохранённый фильтр «список + метка + приоритет + срок» в боковом меню |
| «Выполнено» с фильтрами «Все время» и «Все списки», сгруппировано по дням | Список выполненных без групп и фильтров | Делаем группы по дням и выбор списка |
| «Сводка» за период с группами выполнено, не будет, не завершено, можно скопировать | Нет | Делаем простую версию для отчёта «что сделано за неделю» с кнопкой «Копировать» |
| Меню аватара: настройки, статистика, премиум, выход | Настройки, выход | Делаем статистику: сколько выполнено по дням и по спискам |
| Справка: горячие клавиши, центр помощи, отзыв, блог изменений | Нет | Делаем окно «Горячие клавиши» для ПК. Остальное не нужно |

## Премиум у них (видно по замкам у бесплатного аккаунта)
Фильтры, таймлайн, часть видов календаря, глобальное постоянное напоминание, история изменений и файлы с большими лимитами, участники. У нас бесплатно: фильтры (делаем), история (есть), файлы (до 5 МБ), напоминания без лимита (есть).

## Что нужно прорабу и в TickTick не лежит на виду
Кнопка «Позвонить»: в карточке объекта она уже была, теперь есть и в обычной задаче (номер из названия или заметки). Дублирование объекта-шаблона и печать листа бригаде сделаны 23.10.2026. Показ цен и сумм в сметах не делаем: это отдельный продукт.
