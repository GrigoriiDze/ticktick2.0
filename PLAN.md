# PLAN.md — План полной переработки и сверки интерфейса под оригинальный TickTick

> Обновлён: 25.10.2026
> Статус: **В работе: Блок 1 — Экран Привычек**
> Внимание по ресурсам: свободно ~1 ГБ RAM, работаем строго поочерёдно с минимальным расходом памяти.

## Общая цель
Полное визуальное и функциональное соответствие клона оригинальному TickTick (Web / Desktop / Android) по ресурсам `apk_ref` и референсным скриншотам оригинала.

## Блок 1. Экран «Привычки» (Habits) — [ГОТОВО]

- [x] **1.1. Недельная шкала (`Habit7DaysView`):**
  - Шапка с 7 днями текущей недели (Пон–Вск, числа, кольца общего прогресса за день, подсветка текущего дня).
- [x] **1.2. Карточки привычек в списке (`habit_tab_list_item`):**
  - Иконка 36×36px с цветным фоном и SVG-значком.
  - Название (16px, primary), подпись стрика («⚡ 3 дней 🔥 День 0», 12px, secondary).
  - В десктопном режиме: 7 кликабельных кружков-отметок под днями недели для быстрого чекина за любой день недели.
- [x] **1.3. Правая панель детальной информации:**
  - Графика заглушки (книга, чашка, ручка, звездочки) при отсутствии выбора.
  - При выборе привычки: месячный календарь чекинов, текущий стрик, лучший стрик, процент выполнения за месяц.
- [x] **1.4. Модальное окно создания/редактирования привычки:**
  - Выбор названия, иконки, цвета (8 фирменных цветов), частоты (ежедневно, определённые дни недели) и напоминания.

## Блок 2. Экран «Задачи» (TaskList и детальная карточка) — [ГОТОВО]

- [x] **2.1. Десктопная 3-панельная раскладка:**
  - Левая панель значков (`Rail`) -> боковое меню списков (`Drawer`) -> список задач (`TaskList`) -> правая панель детальной карточки.
  - Полноценная правая панель: редактирование описания (Markdown/Tiptap), чек-лист подзадач, выбор срока, напоминаний, повторов, приоритетов и вложений.
- [x] **2.2. Сортировка и группировка:**
  - Меню «Вид» (по дате, по приоритету, по списку, по названию).
  - Группировка: секции с заголовками и счётчиками («Просрочено», «Сегодня», «Завтра», «Без срока»).
- [x] **2.3. Панель быстрого добавления (Quick Add):**
  - Автопарсинг даты (например, «завтра в 15:00»), кнопки быстрого назначения списка, тега и приоритета.
