## 2. Что исправлено и реализовано 1-в-1 по оригинальному APK

1. **Задачи без тайминга в Календаре (All-day compartment):**
   - Ранее задачи без времени («I want to see you», «You»...) раздували почасовую сетку и сдвигали час 16:00 вниз экрана.
   - Сделано в точности как в оригинале: выделен компактный независимый блок задач сверху с `max-height: 118px` и внутренним скроллом (`overflow-y: auto`, `scrollbar-width: thin`), в котором задачи отображаются аккуратными чипами с закругленным чекбоксом и фоном цвета списка/проекта.
   - Почасовая сетка начинается прямо под шапкой и не сдвигается вниз.

2. **Блокировка зума двумя пальцами (Pinch-to-zoom):**
   - В `index.html`: `maximum-scale=1.0, user-scalable=no, viewport-fit=cover`.
   - В `styles.css`: `html, body, #root { touch-action: pan-x pan-y; }`.
   - В `main.tsx`: перехват multi-touch `touchstart` и `touchmove` (`e.touches.length > 1`) с `{ passive: false }` и `preventDefault()`.
   - В `MainActivity.java`: явное отключение зума в WebView (`setSupportZoom(false)`, `setBuiltInZoomControls(false)`, `setDisplayZoomControls(false)`) во всех жизненных циклах `onCreate`, `onStart`, `onResume`.

3. **Симметричные двухсторонние свайпы задач с 3 кнопками:**
   - **Свайп влево:** при коротком свайпе открывает панель из 3 действий («Изменить» — синий `#4772fa`, «Дата» — оранжевый `#f59e0b`, «Удалить» — красный `#e5484d`). При длинном свайпе (>72% ширины) — моментальное удаление с вибрацией.
   - **Свайп вправо:** при коротком свайпе открывает панель из 3 действий («Выполнено» — зеленый `#30d158`, «Закрепить» — оранжевый `#ff9f0a`, «Пропустить» — фиолетовый `#af52de`). При длинном свайпе (>72% ширины) — моментальное выполнение задачи с вибро- и звуковым откликом.
   - Порог длинного свайпа `fullThresh = Math.max(260, rowW * 0.72)` гарантирует, что короткий свайп не вызывает случайного удаления.

4. **Горизонтальные свайпы в Канбан-доске и боковом меню:**
   - **Канбан:** свайп влево/вправо по экрану переключает активную колонку/пилюлю с плавной прокруткой в фокус (`scrollIntoView`).
   - **Боковое меню (Drawer):** свайп от левого края экрана (`clientX <= 32px`, `dx > 45px`) открывает Drawer; свайп влево по шторке (`dx < -45px`) закрывает её.

5. **Кнопка «Отложить» (перенос просроченных задач):**
   - Добавлено предупреждающее модальное окно: «Отложить задачи? Перенести N просроченных задач на сегодня?» с кнопками «Отмена» и «Перенести».
   - Перенос задач переведён на атомарный батч Firestore (`tasksRepo.batchUpdate` через `writeBatch`), благодаря чему все 12+ задач переносятся мгновенно за один сетевой запрос без подвисаний.
